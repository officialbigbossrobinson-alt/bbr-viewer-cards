Put your own sound files here to replace the built-in ones (.mp3, .wav, .ogg or .m4a).
Name the file after the sound it replaces, for example:

  pack-burst.mp3    the pack bursting open
  reward.mp3        the reward stinger (tier ups, winners)
  impact.mp3        card landing / big hits
  whoosh.mp3        alerts sliding in
  ding.mp3          stat going up
  crowd-cheer.mp3   crowd cheer
  crowd-ooh.mp3     crowd groan
  air-horn.mp3      truck horn
  explosion.mp3     ARC explosions

Restart the app (or refresh the OBS browser source) after adding files.
Only use sounds you have the rights to use on stream.
