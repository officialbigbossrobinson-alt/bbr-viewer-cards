WHAT'S NEW IN v36 (BBR Viewer Cards is now a proper Windows program)
   INSTALL IT
   - Run BBR-Viewer-Cards-Setup-36.0.0.exe. Windows will say "Windows protected your PC" because the
     app isn't signed: press "More info", then "Run anyway". Pick where it goes (or leave it), Install.
   - No Node.js, no black window, no "Start BBR Cards.bat". It's in the Start menu and on the desktop.
   - FIRST TIME: it finds your old BBR-Viewer-Cards folder (Downloads, Desktop, Documents, OneDrive) and
     shows how many cards, logins, clips and songs are in it. Close the old black window first, then press
     "Bring it all over". It makes a copy: your old folder isn't changed. "Choose a folder…" if it's
     somewhere else. Then "Start the app" and OPEN THE DASHBOARD.
   - Windows may ask "Allow BBR Viewer Cards on networks?": tick Private networks and Allow, so your phone
     on the same Wi-Fi can still open the dock.
   - NOTHING CHANGES IN OBS: it still runs on http://localhost:3000 (overlay, Starting Soon, BRB, Big Cam,
     giveaway meter, dock, phone, Stream Deck links all stay the same).
   WHERE YOUR STUFF IS NOW
   - %APPDATA%\BBR Viewer Cards (Setup › App › Open the folder): config.json (settings + logins),
     data\ (cards, clips, photos, music), your own sounds\ and textures\. Updates never touch it.
   THE TRAY (the BBR icon by the clock)
   - Open the dashboard, open the dock in a small window, copy the overlay link, giveaway open / close
     entries, battles off / on, PANIC (hide everything on stream), update, restart, quit.
   - Closing the window keeps it running in the tray, so the overlay keeps working. Quit from the tray.
     If you're live it asks first.
   - Starts with Windows (in the tray). Only one copy runs at a time: opening it again shows the window.
   UPDATES (Setup › App & updates)
   - It checks your GitHub release page by itself, downloads in the background and tells you. A green
     "Update ready" bar shows on the dashboard: What's new, Update now (about 20 seconds; OBS can stay
     open), After my stream, Skip this version.
   - NEVER WHILE YOU'RE LIVE: with "Never install while I'm live" ticked (it is), Update now waits and
     installs by itself about a minute after you end the stream. Untick it and it asks you instead.
   - A FULL BACKUP IS MADE BEFORE EVERY UPDATE (settings, logins, cards, photos, music; not clips).
   - GO BACK TO VERSION <the one before>: downloads that version from the release page, checks it, backs up,
     installs it. Tick "also put my cards and settings back" to go back to the backup from before the
     update too (anything since, like tonight's stream, would be undone).
   - INSTALL FROM A FILE: pick a BBR-Viewer-Cards-Setup-<version>.exe that Claude gave you.
   - Which updates: Normal (tested) or Test versions too.
   BACKUPS (Setup › App & updates)
   - Before every update + at the start of every stream (keep the last 20), or before updates only.
     Back up now, Restore a backup… (a backup of right now is made first, so it can be undone),
     Open the folder. Not while you're live.
   IF SOMETHING'S WRONG
   - Save a report for Claude: one file with the system check and the app's log (no logins). Attach it.
   - Restart the app. If it ever crashes it starts again by itself; if it keeps crashing it asks you.
   - Port: leave it at 3000 (changing it changes every OBS link).
   - "The old BBR Cards window is still running": close the black window, press Try again.
   STILL WORKS THE OLD WAY
   - "Start BBR Cards.bat" in a folder still works exactly as before (data next to server.js), if you
     ever need it. Don't run both at once.

BBR VIEWER CARDS - SETUP
========================

UPDATING FROM AN OLDER VERSION
   From v36: the app updates itself (Setup › App & updates). Your settings and cards are in
   %APPDATA%\BBR Viewer Cards and are kept. Going from v35 or older: install v36 and press
   "Bring it all over" the first time (see WHAT'S NEW IN v36).

1. INSTALL IT
   Run BBR-Viewer-Cards-Setup-<version>.exe ("More info" > "Run anyway" the first time).
   (Running it by hand instead: install Node.js 22+ from https://nodejs.org and use
   "Start BBR Cards.bat".)

2. START IT
   It starts with Windows in the tray (the BBR icon by the clock). Click it for the dashboard.
   The settings page is also at http://localhost:3000 in any browser.

3. CONNECT YOUR PLATFORMS (one-time, each has step-by-step help on the page)
   TWITCH   - create a free app on dev.twitch.tv, paste 2 codes, Connect.
   KICK     - type your channel name and Save: chat, subs, gifted subs, Kicks,
              hosts and follows are tracked straight away.
              Then create a free app in Kick Settings > Developer and "Log in to Kick"
              so the app can also reply in Kick chat and see when you're live.
   YOUTUBE  - create a free Google Cloud project with the YouTube Data API,
              paste 2 codes, Connect. Tracks chat, Super Chats, Super Stickers,
              new members, milestones and gifted memberships while you're live.

4. ADD THE OVERLAY TO OBS
   Sources -> + -> Browser.  URL: http://localhost:3000/overlay
   Width 1920, Height 1080. Tick "Control audio via OBS". Put it above your game.

5. TEST
   Use "Test events" (pick Twitch, Kick or YouTube) and "Test shootout" /
   "Test truck race". Press "Clear test viewers" when done.

EVERY STREAM
   Nothing to start: it's already running in the tray (it starts with Windows).

HOW EACH PLATFORM COUNTS
   Bits (Twitch), Kicks (Kick) and Super Chats/Stickers (YouTube, $1 = 100) all
   raise BIT. Subs, Kick subs and YouTube memberships all raise SUB.
   Raids (Twitch) and hosts (Kick) raise RAI.
   Watch time: Twitch shares who is in chat, so lurkers count. Kick and YouTube
   don't share viewer lists, so watch time there comes from being active in chat.
   Each platform account starts with its own card, but viewers can link them (below).

LINKING ACCOUNTS (one card across Twitch, Kick and YouTube)
   1. On one platform type:        !link          (the app replies with a code)
   2. On the other platform type:  !link CODE
   3. Back on the first one type:  !confirm
   Their cards merge: all stats, subs, bits/Kicks/Super Chats and battle wins are
   combined, and from then on activity on either platform builds the same card.
   The !confirm step means nobody who sees the code in chat can steal a card.
   You can also link cards yourself: tick them in "Viewer cards" on the settings
   page and press "Link as one person". Click a card to unlink an account.

TICKETS, PRIZE POT AND GIVEAWAYS
   The rule: MONEY FILLS THE POT, IT NEVER BUYS TICKETS. That keeps your giveaways
   out of UK lottery law and inside Twitch / YouTube contest rules.
   - Tickets (on each viewer's card) come only from: watching (2 an hour, 3 on two
     linked platforms at once, 4 on three), turning up to a stream (2, plus 1 more
     from the 3rd stream in a row), follow anniversaries (5) and battles. Max 15 a day,
     balance stops at 250, and a balance expires after 60 days without attending.
   - Check-in is automatic: being seen in a stream (Twitch viewer list, or chatting on
     Kick / YouTube) counts once per stream across all platforms.
   - The pot: a share (default 20%) of every sub, gift, membership, bit, Kick and Super
     Chat goes in, split across 5 tiers. Set what you actually receive per sub and per
     100 bits on the settings page. "!pot" or a support event shows the pot meter.
     A monthly prize limit (default 200) stops you overspending: sponsor prizes
     don't count towards it.
   - Tiers: Community Drop (up to 10, followers), Bronze (30), Silver (75), Gold (100),
     Legend Jackpot (250). Higher tiers need a higher CARD tier, which takes weeks of
     loyalty, not spending. Following on any linked platform is required for all.
   - Running one: settings page > Giveaways > pick tier, prize and value > Open entries.
     Viewers type !enter (1 free entry) or !enter 5 (extra entries paid with tickets).
     Close entries > Draw winner. The winner has 10 minutes to type !claim, or press Draw
     again for a redraw. "Test giveaway" shows the whole thing with fake viewers.
   - Afterwards: the winner's tickets are spent, they get a WINNER ribbon and a 30-day
     cooldown on that tier (7 days on all tiers). Everyone else gets half their tickets
     back plus a Lucky Charm (+1 free entry next time in that tier, stacks to 3).
     Nobody's card stats go down.
   - Before your first giveaway, put a short rules page in your panels / description
     (see the plan document): UK only, age, prize and value, how the winner is picked,
     "not sponsored by Twitch / YouTube / Kick", and a privacy line.

WEEKLY GIVEAWAY SCHEDULE (settings page > Giveaways > Weekly schedule)
   One draw a week on your draw day (Thursday by default), building to The Big One:
     1st Thursday of the month  Community Drop   (default prize up to 10)
     2nd Thursday               Bronze Drop      (25)
     3rd Thursday               Silver Drop      (50)
     LAST Thursday              THE BIG ONE: Gold Drop (100)
   A 5th Thursday, or a skipped date (24/25/31 Dec, 1 Jan by default), becomes a
   DOUBLE TICKETS WEEK: no prize, everyone earns tickets twice as fast.
   Tick "Weekly schedule on", set the prizes, Save. From then on the app opens each
   week's draw at your first stream of the week, reminds chat every 30 minutes, and
   shows "this week's draw / The Big One in X days" on stream. YOU press Draw winner
   at the end of the draw-day stream. Scheduled draws are paid from your monthly
   prize limit even if the pot is short. Chat can type !giveaway to see the plan.

WATCHING ON SEVERAL PLATFORMS AT ONCE
   Linked cards earn watch time once, then x1.25 when present on 2 platforms at the
   same time and x1.5 on all 3 (tickets earn faster too). After 10 streams watched on
   2+ platforms a viewer gets the MULTI-PLATFORM ribbon.

HOW CARDS STAY FAIR
   - Early points come quickly; 90+ takes months of real support.
   - Each stat has a daily limit; big one-off spends are banked and added over
     the following days.

     20 streams and 4 streams in the last month.
   - After 7 days away, stats slowly fade. SUB fades once a sub lapses.

IF KICK STOPS WORKING
   Kick's chat feed isn't officially documented and Kick changed it in October 2026.
   Anything the app doesn't recognise is written to data\kick-events.log. Send that
   file over and it can be fixed quickly.
